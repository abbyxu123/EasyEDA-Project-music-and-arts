# 导电材料使用说明

## 可用材料

- 导电涂料：适合画作触摸区域。
- 导电线：适合衣服、袖口、口袋、布艺边缘。
- 导电布：适合大面积触摸区域。
- 金属扣或按扣：适合可拆卸接口。

## 画作建议

- 触摸区域不要太细，建议留出手指可稳定触摸的面积。
- 导电涂料线条要连续，避免中间断裂。
- 触摸点到 PCB 的连线尽量短。
- 可以把连接线藏在画布背面或画框边缘。

## 服装建议

- 电子模块必须可拆卸，避免清洗时损坏。
- 导电线不要直接承受拉力，最好和普通线一起固定。
- 触摸区域不要放在容易误碰的位置。
- 连接器要有防拉扯结构，例如模块袋、魔术贴或暗扣。

## 调试建议

- 先用铜箔胶带测试触摸，再换成导电涂料或导电线。
- 每次只增加一个触摸点，确认稳定后再继续。
- 衣服版本要在穿上、走动、抬手时测试误触发。
