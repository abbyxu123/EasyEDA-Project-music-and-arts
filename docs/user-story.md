# 用户故事与使用场景

## 目标观众

这个项目面向三类人：

- 评委：需要快速理解作品创意、硬件结构和开源价值。
- 创作者：希望把画作、服装、布艺装置做成交互乐器。
- 普通观众：只需要看到“摸画会响、摸衣服会演奏”就能参与。

## 核心故事

展台上有一幅画和一件衣服。观众先看到画面上的星星、花朵、动物或线条。触摸其中一个图案时，画作发出一个音符。另一个人穿着带导电线的衣服，触摸袖口或口袋时，衣服发出鼓点或和弦。两个人一起触摸，画和衣服组成一段小型演奏。

## 画作场景

作为画作者，我希望把导电涂料画进作品中，让画面上的图案变成可触摸的音符区域。这样我不用额外放很多按钮，观众也能自然地通过画面参与演奏。

验收标准：

- 触摸区域是画面的一部分，不是突兀的电子按钮。
- 每个触摸区域有明确声音反馈。
- 画作背面走线整洁，不影响正面观感。

## 服装场景

作为穿戴者，我希望电子模块固定在衣服内层或口袋中，导电线连接到袖口、肩部、胸前图案等位置。触摸这些位置时，衣服可以发出节奏、和弦或音色变化。

验收标准：

- 电子模块可以拆卸。
- 服装穿上后不会明显拉扯接线。
- 走动、抬手时不会频繁误触发。

## 复刻场景

作为开源项目复刻者，我希望拿到 PCB、BOM、固件和教程后，可以把自己的画或衣服接到这块板子上。

验收标准：

- 文档说明每个触摸接口的用途。
- BOM 能看出关键元件型号和替代方向。
- 固件说明能看出触摸通道如何映射到声音。
- 有打板前和打板后的测试清单。

## 比赛展示场景

演示视频建议包含以下画面：

- 作品整体外观。
- 手指触摸画作发声。
- 穿戴者触摸衣服发声。
- PCB 近景，展示这是自制硬件。
- 两人或多人共同演奏。
- 开源资料页面，展示项目可复刻。
