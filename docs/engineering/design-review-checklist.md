# 原理图与 PCB 设计评审清单

## 评审目标

在打板前请至少做一次设计评审。评审不是看图好不好看，而是确认板子回来后能安全上电、能调试、能连接画作和服装。

## 原理图评审

- [ ] 主控供电电压正确。
- [ ] MPR121 供电电压正确。
- [ ] I2C SDA/SCL 接到正确引脚。
- [ ] I2C 上拉电阻明确。
- [ ] MPR121 地址脚处理明确。
- [ ] 若使用 IRQ，引脚接入 MCU 并在 pin map 中记录。
- [ ] 音频模块通信方式明确。
- [ ] 功放输入和输出连接正确。
- [ ] 喇叭接口正负极明确。
- [ ] 电池接口和 USB 供电不会冲突。
- [ ] 电源开关位置在电路上合理。
- [ ] BOOT/RESET/下载电路可用。
- [ ] 调试接口可用。

## PCB 评审

- [ ] 触摸接口在板边，方便接线。
- [ ] T0-T11 丝印清晰。
- [ ] 触摸走线远离功放和喇叭线。
- [ ] 电源线宽度合理。
- [ ] 固定孔位置合理。
- [ ] 固定孔周围无走线风险。
- [ ] USB 接口不被其他元件挡住。
- [ ] 电源开关容易拨动。
- [ ] 模式按键容易按到。
- [ ] 喇叭和电池接口方向合理。
- [ ] 板边无尖角或危险外形。

## 交互评审

- [ ] 画作至少能接 6 路触摸。
- [ ] 服装至少能接 4 路触摸。
- [ ] 电子模块能从服装上拆下。
- [ ] 触摸编号和演示脚本一致。
- [ ] 状态 LED 能辅助调试。

## 文档评审

- [ ] `pin-map.csv` 已更新。
- [ ] `bom-draft.csv` 已更新。
- [ ] `pre-fab-checklist.md` 已勾选。
- [ ] 原理图 PDF 已导出。
- [ ] PCB 预览图已导出。
