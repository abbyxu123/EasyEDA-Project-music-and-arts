# PCB 布局布线约束

## 总原则

首版 PCB 以可调试和稳定演示为主。不要为了板子好看而牺牲接口可达性、丝印清晰度和测试点。

## 推荐板面布局

```text
┌──────────────────────────────────────┐
│ T0 T1 T2 T3 T4 T5                    │  触摸接口区，靠近一侧板边
│ T6 T7 T8 T9 T10 T11                  │
│                                      │
│         MPR121 Touch IC              │
│                                      │
│  ESP32 MCU          UART/I2C Debug   │
│                                      │
│  USB-C   PWR SW     Audio Module     │
│                                      │
│  BAT     3V3 Reg    AMP       SPK    │
└──────────────────────────────────────┘
```

## 触摸输入布线

- 触摸线尽量短、清晰、远离音频功放和电源开关。
- T0-T11 走线不要穿过功放区域。
- 触摸接口集中放在板边，方便画作和服装接线。
- 每一路触摸输入旁边尽量有丝印编号。
- 若有空间，可以给触摸输入保留测试点。

## 电源布线

- USB、电池、稳压、电源开关放在同一区域。
- 功放供电线适当加宽。
- 3.3V 逻辑电源和功放电源要在原理图上命名清楚。
- 电池接口正负极必须在丝印中标出。
- 避免让电源大电流线贴近 MPR121 触摸输入。

## 音频布线

- 功放和喇叭接口靠板边。
- 喇叭线远离 T0-T11。
- 音频输入线不要和触摸线长距离平行。
- 如果有耳机或外接音频接口，避免和喇叭输出混用导致误接。

## 主控与调试

- USB、下载电路、BOOT/RESET 按键要方便操作。
- UART 或 I2C 调试接口保留 2.54mm 间距更方便首版调试。
- 状态 LED 放在正面容易看到的位置。

## 机械约束

- 首版建议控制在 60 mm x 80 mm 内。
- 固定孔建议 4 个，尽量靠近四角。
- 固定孔周围避免走线和放置高元件。
- 板边避免尖角，穿戴场景更安全。
- 接口方向要考虑画框背面和服装模块袋两种安装方向。

## DRC 前自查

- [ ] T0-T11 丝印可读。
- [ ] 电池和喇叭正负极可读。
- [ ] USB、开关、按键不会被接线挡住。
- [ ] 固定孔没有压线。
- [ ] 触摸区、音频区、电源区有基本分区。
- [ ] 主要接口都在板边，方便接线。
