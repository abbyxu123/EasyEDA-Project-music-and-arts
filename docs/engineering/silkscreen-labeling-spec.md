# 丝印与板面标识规范

## 目的

首版 PCB 会被用于调试、展示和开源复刻。丝印不是装饰，它要帮助用户接线、判断方向、避免反接。

## 必须出现的丝印

- 项目名：`Touch Music Controller` 或 `ZhiYin v0.1`
- 版本号：`v0.1`
- 触摸输入：`T0` 到 `T11`
- 电池接口：`BAT + -`
- 喇叭接口：`SPK + -`
- USB：`USB`
- 电源开关：`ON/OFF`
- 模式按键：`MODE`
- 状态灯：`STATUS`
- 调试接口：`UART` 或 `I2C`

## 触摸接口布局标识

建议按两行排列，方便对应画作和服装：

```text
PAINT: T0 T1 T2 T3 T4 T5
WEAR:  T6 T7 T8 T9 T10 T11
```

如果板面放不下 `PAINT` 和 `WEAR`，至少要保证 T0-T11 清楚。

## 极性标识

必须标正负极：

- 电池
- 喇叭
- 外接电源
- LED，若手焊
- 电解电容，若使用

## 版本和链接

建议在板背面预留：

```text
EasyEDA-Project-music-and-arts
github.com/abbyxu123/EasyEDA-Project-music-and-arts
```

如果链接太长，可以只放项目名和二维码位置，二维码放在文档或贴纸上。

## 可读性要求

- 丝印不要被元件压住。
- 丝印不要离焊盘太近。
- 接口方向变化时，丝印应跟随接口方向，避免接线时读反。
- 深色阻焊上用白色丝印更清楚。
