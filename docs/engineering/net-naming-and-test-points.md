# 网络命名与测试点计划

## 目的

统一原理图中的网络命名，并提前规划测试点。首版 PCB 回来后，测试点能帮助快速判断问题来自供电、I2C、触摸输入、音频还是固件。

## 推荐网络命名

| 网络 | 含义 | 备注 |
|---|---|---|
| `VUSB` | USB 输入 5V | 来自 USB-C |
| `VBAT` | 电池输入 | 来自锂电池接口 |
| `VCC_5V` | 5V 系统电源 | 若存在升压或 USB 直供需明确 |
| `VCC_3V3` | 3.3V 逻辑电源 | MCU、MPR121 |
| `GND` | 地 | 全板统一地 |
| `I2C_SDA` | I2C 数据 | MCU 到 MPR121 |
| `I2C_SCL` | I2C 时钟 | MCU 到 MPR121 |
| `MPR_IRQ` | MPR121 中断 | 可选但建议预留 |
| `TOUCH_0` 到 `TOUCH_11` | 12 路触摸输入 | 对应丝印 T0 到 T11 |
| `AUDIO_TX` | 音频模块串口 TX/RX 之一 | 按最终音频方案调整 |
| `AUDIO_RX` | 音频模块串口 TX/RX 之一 | 按最终音频方案调整 |
| `AMP_EN` | 功放使能 | 可选 |
| `SPK_P` / `SPK_N` | 喇叭输出 | 标清正负 |

## 必备测试点

| 测试点 | 网络 | 用途 |
|---|---|---|
| TP_5V | `VCC_5V` 或 `VUSB` | 上电检查 |
| TP_3V3 | `VCC_3V3` | 逻辑电源检查 |
| TP_GND | `GND` | 万用表和示波器参考 |
| TP_SDA | `I2C_SDA` | I2C 调试 |
| TP_SCL | `I2C_SCL` | I2C 调试 |
| TP_IRQ | `MPR_IRQ` | 触摸中断调试 |
| TP_AUDIO | 音频输入或输出 | 音频链路调试 |

## 可选测试点

- `TOUCH_0` 到 `TOUCH_11`，如果板面空间允许。
- `VBAT`，用于电池供电排查。
- `AMP_EN`，用于判断功放是否被正确打开。

## 测试点布局建议

- 电源测试点放在电源区附近。
- I2C 测试点放在 MCU 和 MPR121 之间，便于夹表笔。
- 测试点丝印使用 `TP_` 前缀。
- 测试点不要放在服装模块固定孔附近，避免被螺丝或布料挡住。
