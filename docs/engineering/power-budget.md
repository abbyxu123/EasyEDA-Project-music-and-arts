# 电源预算草案

## 目的

这个文件用于在打板前估算电流，帮助判断 USB、电池、稳压芯片、开关、走线宽度和功放方案是否合理。

## 首版供电目标

- 桌面调试：USB 5V 供电。
- 服装演示：单节锂电池供电，电池模块可拆卸。
- 逻辑电源：3.3V。
- 音频功放：按所选功放决定 3.3V 或 5V。

## 估算电流

| 模块 | 估算电流 | 备注 |
|---|---:|---|
| ESP32 | 80-250 mA | Wi-Fi/蓝牙不用时可低一些 |
| MPR121 | 1-5 mA | 很低 |
| 音频播放模块 | 20-100 mA | 与模块和音量有关 |
| 功放 + 喇叭 | 100-600 mA | 与音量、阻抗、功率有关 |
| 状态 LED | 2-10 mA | 可限流 |
| 余量 | 100-200 mA | 首版建议留余量 |

## 初步判断

- USB 供电建议按至少 1A 设计余量。
- 电池演示建议使用带保护的锂电池或成熟电源模块。
- 如果使用较大功率喇叭，音频功放电源要单独谨慎处理。
- 不建议首版追求很大音量，展示用小音箱或外接音箱更稳。

## 打板前必须确认

- [ ] 主控是裸 ESP32 模组还是开发板结构。
- [ ] 功放芯片型号和供电电压。
- [ ] 喇叭阻抗和功率。
- [ ] 是否板载锂电充电。
- [ ] USB-C 只供电还是同时下载。
- [ ] 3.3V 稳压器最大输出电流。

## 设计建议

- 电池接口必须标正负极。
- 功放电源走线不要太细。
- 如果功放电流较大，避免与触摸检测共用过长细线。
- 状态 LED 不要太亮，避免浪费电池。
- 首版可以预留电池检测，但不是必须实现完整电量显示。
