# 展示方案

## 展示标题

织音画布：可演奏的画与衣

## 视频结构

1. 展示一幅画，手指触摸画中的图案发出旋律。
2. 展示衣服上的导电线和触摸区域，触摸后发出鼓点或和弦。
3. 展示 PCB，说明它是连接画和衣服的核心。
4. 双人演奏：一人演奏画作旋律，一人演奏服装节奏。
5. 展示开源资料：原理图、PCB、BOM、代码、制作步骤。

## 评审重点

- 创意是否一眼能懂
- 硬件是否自己设计
- 文档是否能复刻
- 演示是否稳定
- 作品是否兼具艺术性和实用扩展性

## 展台准备

- 画作成品
- 服装成品
- 触摸音乐 PCB
- 小喇叭或外接音箱
- 充电电池和备用 USB 电源
- 接线图
- 二维码链接到开源仓库
