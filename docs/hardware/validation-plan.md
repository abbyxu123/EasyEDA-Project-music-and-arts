# 硬件验证计划

## 打板前验证

在画 PCB 前，建议先用开发板和模块验证以下内容：

- ESP32 可以读取 MPR121 的 12 路触摸状态。
- 导电涂料触摸区域可以稳定触发。
- 导电线长度达到服装实际需要时仍能稳定触发。
- 音频模块可以按通道播放不同声音。
- 触摸输入和音频输出同时工作时不会明显互相干扰。

## 首版 PCB 回来后验证

### 上电检查

- [ ] 不插电池，只用 USB 上电。
- [ ] 测量 5V 和 3.3V 电压。
- [ ] 检查 MCU 是否能下载固件。
- [ ] 检查状态 LED 是否可控。

### 触摸检查

- [ ] 每一路 T0 到 T11 单独触发。
- [ ] 多路触摸不会串扰。
- [ ] 导电涂料连接后稳定触发。
- [ ] 导电线连接后稳定触发。
- [ ] 穿戴服装时测试误触发。

### 音频检查

- [ ] 每一路触摸能触发正确声音。
- [ ] 音量足够展示。
- [ ] 喇叭无明显破音。
- [ ] 音频播放时触摸不乱跳。

### 作品联调

- [ ] 画作能独立演奏。
- [ ] 服装能独立演奏。
- [ ] 画作和服装能同时接入演示。
- [ ] 演示视频中能稳定完成一段表演。

## 常见问题记录

| 问题 | 可能原因 | 处理方式 |
|---|---|---|
| 触摸一直触发 | 阈值太低、导线太长、环境噪声 | 提高阈值，缩短线长，重新校准 |
| 触摸不灵敏 | 触摸面积太小、导电涂料断开 | 加大触摸区，检查连通性 |
| 播放有杂音 | 功放供电或布线问题 | 分离音频和触摸走线，检查电源 |
| 衣服误触发 | 布料移动、人体接触面积变化 | 提高服装模式阈值，固定导电线 |
