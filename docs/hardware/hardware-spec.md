# 硬件规格草案

## 首版目标

首版 PCB 以稳定演示为目标，优先保证触摸检测可靠、音频输出清楚、接口容易连接画作和衣服。

## 推荐硬件架构

```text
USB-C / 锂电池
      ↓
电源管理
      ↓
ESP32 主控
      ↓
MPR121 电容触摸芯片
      ↓
音频模块 / DAC / PWM 音频
      ↓
功放芯片
      ↓
喇叭或音频接口
```

## 主要模块

| 模块 | 推荐作用 | 备注 |
|---|---|---|
| ESP32 | 主控、蓝牙扩展、逻辑控制 | 适合后续支持蓝牙 MIDI |
| MPR121 | 12 路电容触摸输入 | 比 MCU 直接触摸更适合多通道 |
| 音频模块 | 播放音色或音效 | 首版可用 DFPlayer Mini 或类似方案验证 |
| 功放芯片 | 推动小喇叭 | 注意与触摸输入分区 |
| USB-C | 供电、下载、调试 | 首版也可使用开发板接口 |
| 锂电池接口 | 服装演示供电 | 必须有开关和保护思路 |

## 外部连接

- 触摸输入端子：建议使用排针、弹簧端子或 JST 接口。
- 画作连接：导电涂料触摸点连接到触摸输入，公共地线按触摸方案决定是否需要。
- 服装连接：导电线通过可拆卸接口连接，电子板固定在口袋或内层模块袋中。
- 音频输出：首版优先使用 3.5mm 或小喇叭接口，减少蓝牙调试复杂度。

## PCB 设计重点

- 触摸输入走线远离功放、电源开关和喇叭走线。
- 触摸通道接口旁边加清晰丝印，例如 T0 到 T11。
- 电池、电源、喇叭接口必须防呆或有明显正负极标识。
- 预留固定孔，方便固定在画框背面或衣服模块袋中。
- 板子边缘避免尖角，穿戴使用时更安全。
