# PCB v0.1 需求

## 版本目标

v0.1 是首版验证板，目标是证明“同一块板可以稳定连接导电涂料画作和导电纺织服装并触发声音”。首版不追求小型化和外观极致，优先保留调试空间。

## 必须实现

- 12 路触摸输入接口
- MCU 与 MPR121 通信
- 音频触发输出
- 小喇叭或外部音频输出
- USB 供电
- 电池供电接口
- 电源开关
- 模式切换按键
- 状态 LED
- 固定孔

## 建议预留

- I2C 扩展接口
- UART 调试接口
- 电池电压检测
- 功放使能控制
- 备用 GPIO
- 外接地线或屏蔽测试点

## 尺寸建议

- 首版板子不必太小，建议优先控制在 60 mm x 80 mm 以内。
- 固定孔建议 4 个，孔径按 M2 或 M3 选择。
- 接口尽量放在板边，方便画作和衣服走线。

## 接口建议

| 接口 | 建议形式 | 说明 |
|---|---|---|
| 触摸输入 | 排针 / JST / 弹簧端子 | 首版优先方便调试 |
| 喇叭 | 2P 插座 | 标清正负极 |
| 电池 | JST-PH 2P | 标清正负极 |
| USB | USB-C | 供电和下载 |
| 调试 | 2.54mm 排针 | 串口或 I2C 调试 |

## 不建议首版加入

- 复杂无线同步
- 多块板组网
- 高功率扬声器
- 不可拆卸服装电子模块
- 过度小型化
