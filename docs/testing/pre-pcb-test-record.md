# 打板前测试记录

## 为什么要先测试

这个项目的风险不在“触摸能不能发声”这个概念，而在导电材料的稳定性。导电涂料、导电线、人体接触、衣服晃动、音频功放都会影响触摸检测。打板前必须先用模块验证，否则 PCB 做出来后很难判断是电路问题、材料问题还是程序阈值问题。

## 推荐测试材料

- ESP32 开发板
- MPR121 12 路触摸模块
- 面包板和杜邦线
- 铜箔胶带
- 导电涂料
- 导电线
- 一小块布料
- 小喇叭或外接音箱
- 万用表

## 测试 2：导电涂料画作触摸

目标：确认导电涂料画出的图案可以作为触摸电极。

步骤：

1. 在纸或画布上画 3 个触摸区域。
2. 每个区域用导线连接到 MPR121。
3. 测试干燥前后触摸效果。
4. 记录触摸面积、线长和稳定性。

## 测试 3：导电线服装触摸

目标：确认导电线在布料上可以稳定触发。

步骤：

1. 在布料上缝 3 到 4 个触摸区域。
2. 使用不同线长测试，例如 20 cm、40 cm、60 cm。
3. 静止、穿戴、抬手、走动时分别测试。
4. 记录误触发情况。

## 测试 4：音频干扰

目标：确认音频播放和功放不会明显干扰触摸检测。

步骤：

1. 同时运行触摸检测和音频播放。
2. 让喇叭以展示音量播放。
3. 静置观察触摸输入是否乱跳。
4. 触摸多个通道，观察响应是否变慢。

- 中等音量下触摸检测稳定。
- 播放声音时不会连续误触发。

## 打板前结论

只有当以下条件满足后，才建议开始 PCB v0.1：

- [ ] MPR121 12 路基础触摸通过。
- [ ] 导电涂料触摸通过。
- [ ] 导电线服装触摸通过。
- [ ] 音频播放与触摸同时运行通过。
- [ ] 已确定触摸接口、音频接口、电源接口和固定孔需求。
