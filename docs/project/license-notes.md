# 开源许可证说明

## 当前选择

仓库当前使用 MIT License。它简单、常见，适合固件代码、说明文档和早期项目协作。

## 需要注意

MIT License 对硬件设计文件的约束比较弱。如果后续项目进入正式开源硬件发布阶段，可以考虑把许可证拆分得更清楚：

- 固件代码：MIT License
- 文档和教程：CC BY-SA 4.0
- 硬件设计：CERN-OHL-S 或 CERN-OHL-P

## 现阶段建议

在打板前阶段，先保留 MIT License，避免让项目过早复杂化。等 EasyEDA 原理图、PCB、Gerber 和固件都稳定后，再决定是否增加更适合硬件的许可证说明。
