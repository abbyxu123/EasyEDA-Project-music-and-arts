# 原理图设计记录

这个文件用于在画 EasyEDA 原理图时记录每个模块的选择和连接理由。它不是最终原理图，但能帮助后续复盘和开源说明。

## 主控

候选：

- ESP32-WROOM
- ESP32-S3
- RP2040

首版建议：

- 优先使用 ESP32 系列，因为资料多，后续可扩展蓝牙 MIDI。
- 如果使用 ESP32 开发板验证，打 PCB 时要确认是直接上模组，还是保留开发板座子。

待确认：

- [ ] 最终主控型号
- [ ] 下载方式
- [ ] USB 转串口方案
- [ ] 供电电压

## 触摸检测

候选：

- MPR121 12 路电容触摸芯片
- ESP32 内置电容触摸

首版建议：

- 优先使用 MPR121，原因是 12 路输入更适合画作和服装同时演示。

待确认：

- [ ] MPR121 I2C 地址
- [ ] I2C 上拉电阻
- [ ] IRQ 引脚是否接入 MCU
- [ ] 触摸输入接口形式

## 音频

候选：

- DFPlayer 类音频播放模块
- ESP32 I2S DAC
- PWM 简单音频
- MIDI 输出到外部音源

首版建议：

- 如果目标是尽快稳定演示，先用音频播放模块或 I2S 音频。
- 如果想提升技术表达，可以预留 MIDI 或 I2S 扩展接口。

待确认：

- [ ] 音频播放方案
- [ ] 喇叭阻抗和功率
- [ ] 是否需要 3.5mm 音频接口
- [ ] 功放芯片型号

## 电源

首版建议：

- USB 供电作为主要调试方式。
- 预留锂电池接口用于服装演示。
- 增加电源开关。

待确认：

- [ ] 是否板载充电
- [ ] 电池接口型号
- [ ] 3.3V 稳压方案
- [ ] 功放电源是否与逻辑电源分开处理

## 接口

触摸接口建议清晰编号：

```text
T0 T1 T2 T3 T4 T5
T6 T7 T8 T9 T10 T11
```

打板前必须在丝印中标清：

- 项目名
- 版本号 v0.1
- 触摸编号
- 电池正负极
- 喇叭正负极
- USB/Power/Mode
