# 结构与安装说明

## 设计目标

PCB 需要同时适合画作和服装两种安装方式。首版结构不追求隐藏到完全看不见，优先保证安全、稳定、可拆卸和方便调试。

## 画作安装

推荐方式：

- PCB 固定在画框背面。
- 触摸线从画布背面连接到导电涂料区域。
- 喇叭可以固定在画框背面或画框底部。
- USB 或电池接口留在侧边，方便供电。

注意事项：

- 正面不要露出杂乱接线。
- 导电涂料触摸区域要和画面融合。
- 画框背面预留检修空间。
- 触摸线不要和音频线捆在一起。

## 服装安装

推荐方式：

- PCB 放在内层口袋或可拆卸模块袋中。
- 触摸区域使用导电线、导电布或金属按扣。
- 电子模块和服装之间使用可拆卸接口。
- 电池单独固定，避免晃动拉扯接口。

注意事项：

- 电子模块必须可拆卸，不能直接水洗。
- 导电线不要承担主要拉力。
- 触摸区域避免放在腋下、腰侧等高误触位置。
- 接口附近要有布料固定或魔术贴减轻拉扯。

## PCB 外形建议

- 首版尺寸建议不超过 60 mm x 80 mm。
- 四角倒圆或避免尖角。
- 预留 4 个固定孔。
- 接口尽量放在板边。
- 电源开关和 USB 口放在容易触达的位置。

## 可拆卸方案

| 场景 | 连接方式 | 备注 |
|---|---|---|
| 画作 | 排针、螺丝端子、JST | 优先可靠和易调试 |
| 服装 | JST、按扣、磁吸接口 | 优先可拆卸和抗拉扯 |
| 喇叭 | 2P 插座 | 标注正负极 |
| 电池 | JST-PH | 必须防止反接 |

## 打板前结构检查

- [ ] 板子能放进预定画框背面。
- [ ] 板子能放进预定服装模块袋。
- [ ] 固定孔不会与元件或走线冲突。
- [ ] 触摸接口数量足够。
- [ ] 触摸接口方向方便接线。
- [ ] 电池和喇叭不会拉扯主板。
