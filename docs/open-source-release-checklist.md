# 开源发布检查清单

这个清单用于提交到 GitHub、立创开源平台或比赛页面前检查资料完整度。

## 项目介绍

- [ ] README 能说明项目是什么。
- [ ] 有项目实物照片或效果图。
- [ ] 有一句话项目简介。
- [ ] 有系统结构图或文字结构说明。
- [ ] 有演示视频链接或视频计划。

## 硬件资料

- [ ] 原理图文件已上传。
- [ ] PCB 文件已上传。
- [ ] Gerber 文件已上传。
- [ ] BOM 已更新为实际用料。
- [ ] Pick and Place 文件已上传，若需要 SMT。
- [ ] PCB 版本号清楚，例如 v0.1。
- [ ] 接口、正负极、触摸编号丝印清楚。

## 固件资料

- [ ] 固件源码已上传。
- [ ] README 写明开发环境。
- [ ] 写明依赖库。
- [ ] 写明如何烧录。
- [ ] 写明触摸通道和声音映射。

## 制作教程

- [ ] 画作制作步骤。
- [ ] 服装制作步骤。
- [ ] 接线方式。
- [ ] 调试方法。
- [ ] 常见问题。

## 参赛资料

- [ ] 作品标题统一。
- [ ] 赛道定位清楚。
- [ ] 创新点不夸大。
- [ ] 明确哪些是已完成，哪些是后续计划。
- [ ] 文档符合开源规则，没有使用不能公开的素材或代码。

## 首版发布前判断

如果以下三项还没完成，不建议对外宣称项目完成：

- [ ] 至少一块 PCB 或模块样机能稳定演示。
- [ ] 画作和服装至少各有一个可演奏样例。
- [ ] 仓库资料足够让别人理解如何复刻。
