# 演示视频脚本

## 视频目标

用一段短视频让观众和评委快速理解三件事：

- 这不是普通画作，画可以演奏。
- 这不是普通衣服，衣服也可以演奏。
- 背后有一块自制开源 PCB，把导电材料变成音乐输入。

## 建议结构

### 1. 开场：作品整体

画面：画作挂在桌面或墙上，旁边有人穿着可演奏服装。

旁白或字幕：

```text
这是一套可演奏的画与衣。我们用导电涂料、导电线和自制触摸音乐 PCB，把日常材料变成乐器。
```

### 2. 画作演奏

画面：手指触摸画中的不同图案，发出不同音符。

重点：

- 每次触摸声音要清楚。
- 镜头能看到手和画面。
- 不要只拍 PCB，要先拍作品效果。

### 3. 服装演奏

画面：穿戴者触摸袖口、肩部、口袋或胸前图案，触发鼓点、和弦或音效。

重点：

- 服装上的导电线或导电布要能看出设计感。
- 电子模块最好露出一小段镜头，证明不是后期配音。

### 4. 联合演奏

画面：一人摸画演奏旋律，另一人摸衣服演奏节奏。

建议分工：

- 画作：旋律音符
- 衣服：鼓点、和弦、低音或音色切换

### 5. 硬件展示

画面：PCB 近景、接口、触摸线、喇叭、电池。

字幕：

```text
核心是一块 12 路触摸音乐控制板，可以连接导电涂料、导电线、导电布等材料。
```

### 6. 开源资料展示

画面：GitHub 或立创开源页面，展示 README、BOM、原理图、PCB、代码、制作教程。

字幕：

```text
项目资料开源，其他创作者可以复刻自己的画作乐器或服装乐器。
```

## 拍摄清单

- [ ] 画作全景
- [ ] 画作触摸特写
- [ ] 服装全景
- [ ] 服装触摸特写
- [ ] PCB 近景
- [ ] 接线和固定方式
- [ ] 联合演奏片段
- [ ] 开源资料页面

## 避免的问题

- 不要只讲概念，必须有实际触摸发声。
- 不要把声音后期配得太假，最好保留现场触摸和声音同步。
- 不要让画面看起来像现成模块拼接，必须展示自制 PCB 和接口设计。
- 不要一次展示太多功能，先让观众记住“画和衣服能一起演奏”。
