# 织音画布：可演奏的画与衣

一个基于导电涂料、导电纺织线和自制触摸音乐 PCB 的互动音乐硬件项目。项目目标是把一幅新画作和一件可穿戴服装同时变成乐器：画作负责旋律，服装负责节奏、和弦或音色控制，形成可以表演、可以复刻、可以继续扩展的开源硬件作品。

## 项目定位

- 参赛方向：生活创意 + 艺术交互 + 开源硬件
- 推荐赛道：初级赛道，按准高阶完成度制作
- 核心作品：一块可接导电材料的触摸音乐控制板
- 展示形态：可演奏画作 + 可演奏服装 + 双人或多人小型表演

## 核心功能

- 支持 8 到 12 路触摸输入
- 支持导电涂料、导电布、导电线、金属扣等触摸材料
- 支持画作和服装两种外接载体
- 支持钢琴、鼓、小提琴或合成器等音色方案
- 支持外接喇叭、耳机或蓝牙音箱扩展
- 支持电池供电，电子模块可拆卸

## 系统结构

```text
导电涂料画作 / 导电纺织服装
        ↓
触摸输入接口
        ↓
触摸检测芯片或 MCU 电容触摸通道
        ↓
主控 MCU
        ↓
音频播放 / MIDI / 音色合成
        ↓
功放 + 喇叭 / 耳机 / 外部音箱
```
