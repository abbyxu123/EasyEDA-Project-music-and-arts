# 打板前 PCB 检查清单

## 电源

- [ ] USB-C 供电方向和引脚确认
- [ ] 电池接口正负极确认
- [ ] 电源开关位置合理
- [ ] 3.3V / 5V 电源网络命名清楚
- [ ] 主控、触摸芯片、音频模块电压匹配
- [ ] 功放供电电流足够

## 触摸输入

- [ ] T0 到 T11 丝印清楚
- [ ] 触摸输入走线远离功放、喇叭、电源开关
- [ ] 长导线连接时预留调试空间
- [ ] 接口机械强度足够
- [ ] 每路输入都有测试点或易接触位置

## 音频

- [ ] 喇叭接口正负极标注
- [ ] 音频线远离触摸输入线
- [ ] 功放芯片散热和供电检查
- [ ] 耳机或外接音箱接口不会与喇叭输出冲突

## 机械结构

- [ ] 板子尺寸适合画框背面和服装模块袋
- [ ] 固定孔位置不压到走线
- [ ] 板边无尖锐外形
- [ ] USB、开关、音量、接口方向方便使用
- [ ] 服装使用时可拆卸电子模块

## 丝印

- [ ] 项目名和版本号
- [ ] T0-T11 触摸编号
- [ ] 电池正负极
- [ ] 喇叭正负极
- [ ] USB、电源、模式按键标识
- [ ] GitHub 或项目链接位置预留

## 生产文件

- [ ] DRC 通过
- [ ] ERC 通过
- [ ] Gerber 预览无缺层
- [ ] BOM 型号与封装匹配
- [ ] Pick and Place 坐标方向检查
- [ ] 首版版本号标为 v0.1
