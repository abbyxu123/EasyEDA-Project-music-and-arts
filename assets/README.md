# Assets

Place project media files here.

Suggested files:

- `cover.jpg` project cover
- `painting-demo.jpg` playable painting photo
- `wearable-demo.jpg` playable clothing photo
- `pcb-front.png` PCB preview front side
- `pcb-back.png` PCB preview back side
- `demo-video-cover.jpg` video cover

Avoid committing very large raw video files. Add links to hosted videos in `docs/showcase-plan.md`.
